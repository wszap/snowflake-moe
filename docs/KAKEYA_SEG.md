# 挂谷翻转塞 · 换挂载位置（沿序列段）

## 为什么要换

v6 把翻转塞挂在【每层每个 token 的 delta】上（逐位置的空间变换）。实测：

| 配置 | val_loss | θ/α 绝对值 |
|---|---|---|
| K=0 基线 | 1.7288 | — |
| K=8，零初始化 | 1.7286 | 0.0132（没启用） |
| K=8，α 强制 0.1 | 1.7422 | 被压回 0.0750（用了反而更差） |

在那个位置上，翻转塞变成「又一个逐 token 变换层」，**跟 dense FFN 抢同一份工作而且抢不过**，模型主动想关掉它。

它真正被设计来解决的是另一件事：**位置与位置之间，信息流是断的**——难缠的、纠缠成一团的东西没人攒着往下游带。

## 新挂载点

序列 T 切成 S 段，维护「翻转片上的存货」h：

```
段 s 读：  用【上一段末尾】留下的 h（只含段 1..s-1 ⇒ 严格因果）
段 s 翻：  h ← 绕轴旋转（Givens），保范
段 s 攒：  h ← h + 注入门 × 本段摘要 g_s
段 s 写：  out_s = seg_s + 输出门 × h
```

物理对应：

| 物理装置 | 算法 |
|---|---|
| 翻转片上的存货 | carry h |
| 绕两个支点翻转 | Givens 旋转（保范，只改方向） |
| 密封圈扣下难缠的 | 注入门 |
| 送到下游（选的 B，不是丢弃） | 输出门 |
| 沿管道一路带下去 | 沿段推进 |

## 重要修正：Givens 旋转，不是 Householder 插值

之前用的 `y = x − 2α(x·u)u`，分解后**沿轴分量被乘 (1−2α)**：

```
α=0    → ×1      恒等   ✅
α=1    → ×−1     保范   ✅
α=0.5  → ×0      清零   ❌
α=0.66 → ×−0.33  缩短   ❌
```

**只有 α=0 或 α=1 才保范，中间任何值都在收缩。** 跨位置传递时 carry 会被逐段衰减到 0，对状态传递是致命的。

而且物理建模错了：翻转片是**绕两个支点连成的轴**转，在 d 维里是在**一个平面内旋转** = **Givens 旋转**；Householder 反射是镜像（保持 d−1 维超平面），不是绕轴转。

**Givens 旋转任意角度都保范**——转 30° 和转 180° 一样。这才配得上「两个支点稳住，永远不掉」。

数学自检实测（θ = 0 / 0.3 / 0.785 / 1.5 / π）：

```
|h| 比值 = 1.0000000000（全部严格守恒）
```

## 与 v6 的区别

| | v6 | v7 |
|---|---|---|
| 挂在 | 逐 token 的 delta | 整条残差流，沿位置推进 |
| 做什么 | 又一个空间变换 | 跨位置信息通道 |

## 已知局限（诚实）

1. **正交旋转不能缩放。** 补了一个 `decay_gate`（零初始化，默认不衰减）来提供收缩能力。
2. **串行 S 段。** 段数是串行的，S 越大越慢。当前 S=8。
3. **能表示 ≠ 学得会。** 数学自检是理论可达，不代表梯度下降找得到。
4. **这是第三次改挂载/算子。** 前两次（v6 逐 token、Householder）都失败了。不承诺这次能成。
